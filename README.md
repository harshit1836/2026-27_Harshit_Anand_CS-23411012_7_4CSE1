##  Project  
— LinkedIn Integration Module 

## work
The LinkedIn Integration Module is a FastAPI backend service for a larger social-media automation tool. It connects a user account through LinkedIn OAuth 2.0, retrieves profile information and allows text and image posts to be published. The repository explicitly notes that scheduling/auto-posting at a future time is a separate module being built by another teammate.

•	OAuth 2.0 login using LinkedIn's authorization flow.

•	Profile fetching for connected users.

•	Text-post publishing and image-post publishing.

•	Disconnect functionality for removing saved account/token information.

•	Automatic redirect back to the frontend after authentication.

•	Dockerized deployment for consistent development environments.

•	Demo HTML/JavaScript frontend for endpoint testing.
